# 8. Reference Tools & Resources

- **[Interactive Fingering Chart Viewer](fingering_viewer.html):** A dedicated web application to view and practice the fingerings, laid out for the one-handed mechanism. The chart itself is the standard baroque chart, since the keys change which finger works a hole rather than which holes are open.
  - **Features:** Supports both Standard pitch names (`C`, `D`, `E`) and Solfège notation (`Do`, `Re`, `Mi`), dynamic Treble clef staff visualization with octave placement and ledger lines, search filtering, and print/PDF export via `@media print` stylesheets.
  - **Standalone Use:** Can be opened directly in any modern web browser or used offline with `fingering_soprano.csv` beside it.
- **[SoloABec Soprano 440 Build Guide (Chapter 10)](10-soloabec-soprano-440-v1.md):** Complete 3D printing and assembly parameters for the standard soprano model in C.
- **Design Compliance and History:** Historical background on one-handed woodwinds (including expired patents) can be found in [Background & Inspiration](3-background-and-inspiration.md). Open-source licensing and IP compliance details are listed in [Project and Instrument Details and Contexts](4-project-and-instrument-details-and-contexts.md).
