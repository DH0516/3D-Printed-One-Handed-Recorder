7. Model Information

The project supports multiple variants of the same one-handed soprano recorder. All variants share one fingering chart (see the fingering viewer and the machine-readable model data in models/).

  • A1, Soprano: the standard model, described by the Model A1 documentation. The thumb key operates similar to the "A" key, to be pushed with the joint of the index finger, sideways. This particular design involves avoiding the usage of the thumb completely. Right-handed by default; the design is based on a resizing of a historical instrument by J.H. Rottenburgh (originally estimated to be pitched at A = 405 to 415 Hz) to modern pitch (A = 440 Hz). For left-handed play, the design must be flipped horizontally (mirrored along the bore axis). * Note for organology specialists: We can likely produce custom model designs based on different historical models upon request.
  • A2: A1 with key 1, the octave key, moved to the back of the body as a thumb key.
