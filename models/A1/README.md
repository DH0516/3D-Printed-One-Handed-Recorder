# One-Handed Recorder Soprano A1 (OHR-Soprano-v0.1)

The standard model. One-handed soprano recorder in C at A = 440, right-handed
by default (the design mirrors along the bore axis for left-handed play),
mating with any standard plastic soprano recorder head joint. Four printed
keys close toneholes 1 to 4; holes 5 to 8 are finger holes.

- `model.json`: tonehole map and fingering chart (10 holes, 26 fingerings,
  C5 to C#7).
- Print files: published at first release, as per-part files in several
  pin-bore sizes to fit different printers.
