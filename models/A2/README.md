# One-Handed Recorder Soprano A2

A1 with the thumb key at the back. Key 1, the octave lever, relocates from the
key cluster to the back of the body: hole 1 with its key, mount, and pin
holder rotate -213.6 degrees about the bore axis, so hole 1 is drilled at
bearing -103.6 instead of 110.0. Keys 2 to 4 and all finger holes are
unchanged, and the fingering chart is identical to A1; only the physical
location of key 1 differs.

- `model.json`: tonehole map and fingering chart (10 holes, 26 fingerings,
  C5 to C#7).
- Status: pending first release.
